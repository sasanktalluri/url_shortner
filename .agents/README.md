# AI-collaboration traceability

This folder is the record of *how* this repo was built with AI assistance, not *what* it does
(that's `README.md`). It exists to satisfy the assignment's explicit ask for traceability —
what was generated, what was edited or rejected and why, what was validated and how.

- `engineering-log.md` — chronological narrative: requirement understanding, task decomposition,
  each major decision and reversal, bugs found by actually running the app, and validation
  performed. Deliberately excludes commit-level detail (hashes, diffs) — that's what `git log` is
  for; this is the reasoning that doesn't show up in a diff.
